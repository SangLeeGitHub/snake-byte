# Snake Byte - Apple II Edition

A retro Apple II-style snake game with CRT monitor effects, level system, sound, and mobile touch support.

## How to Play

Open `index.html` directly in your browser. No installation or server required.

## Controls

- **Arrow Keys**: Move
- **Mobile**: On-screen buttons or swipe

## Development

- **AI Model**: Gemma 4 31B
- **Tool**: OpenCode
- **GPU**: RTX 3090 Ti
